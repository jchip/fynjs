fynjs

Package and monorepo tools for node.js

fyn is a fast package manager. fynpo is a zero setup monorepo manager built on it. The rest are the small packages they are made from.

fyn

The package manager

  • Treats your disk as a registry. Depend on local copies of packages.
  • Hardlinks from a shared store save disk space and install time.
  • Links live source folders, so changes show up right away.
  • Reads your .npmrc and existing lockfiles.
npm i -g fyn
cd your-project
fyn

fynpo

The monorepo manager

  • Put existing npm packages together. No changes needed.
  • Local packages install in their published form. No symlinks, no hoisting.
  • Each app stays self contained, ready to copy into a container.
  • Bootstraps and runs scripts in topological order.
  • Versions, writes changelogs and publishes.
npm i -g fynpo-cli
cd your-monorepo  # has fynpo in devDependencies
fynpo
