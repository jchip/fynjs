    Class InflightStore<V>

    Keyed store of in-progress work, with start-time and last-check-time tracking.

    This is the generic core: it stores any value type V under any RecordKey and knows nothing about promises. Inflight builds promise deduplication on top of it.

    item-queue uses this directly - it tracks { item, promise } records keyed by an incrementing number, which is neither a promise nor a string, so it needs the core rather than Inflight (FJM-26).
